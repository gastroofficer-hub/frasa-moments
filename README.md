# FRÁŠA MOMENTS

Create a modern, premium, responsive website for a catering company specializing in canapés, finger food, savory bites, and mini desserts.

Brand style:

- Elegant, luxurious, minimalistic.

- White background with dark accents and gold details.

- Premium catering feeling suitable for weddings, corporate events, birthdays, conferences, and VIP parties.

- High-quality food photography with smooth animations.

- Rounded cards, soft shadows, glassmorphism effects where appropriate.

- Mobile-first responsive design.

Website structure:

1. Hero Section

- Large headline:

  "Premium Catering for Every Occasion"

- Subtitle:

  "Fresh canapés, finger food, savory specialties, and handcrafted mini desserts delivered with elegance."

- CTA buttons:

  - Order Now

  - View Menu

- Background featuring beautifully arranged catering platters.

2. Why Choose Us

Display 4 feature cards:

- Fresh Ingredients

- Handmade Daily

- Fast Delivery

- Premium Presentation

3. Product Categories

Beautiful grid with images:

- Canapés

- Finger Food

- Savory Selection

- Mini Desserts

- Sweet Catering

- Party Platters

Each category opens a detailed gallery.

4. Featured Products

Modern cards including:

- Image

- Product Name

- Short Description

- Price

- Add to Cart button

5. Catering for Every Event

Cards for:

- Weddings

- Corporate Events

- Birthdays

- Family Celebrations

- Conferences

- Private Parties

6. Gallery

Large masonry image gallery with hover animations.

7. Customer Reviews

Modern testimonial slider with customer photos and ratings.

8. Ordering Process

Timeline:

1. Choose Products

2. Send Inquiry

3. Confirmation

4. Preparation

5. Delivery

9. FAQ

Accordion with common questions:

- Minimum order

- Delivery areas

- Allergens

- Payment methods

- Custom catering

10. Contact

Include:

- Contact form

- Phone

- Email

- Address

- Google Maps integration

- Social media icons

11. Footer

Include:

- Navigation

- Business information

- Opening hours

- Copyright

- Privacy Policy

- Terms & Conditions

Additional Features:

- Shopping cart

- Product filtering

- Search bar

- Wishlist

- Sticky navigation

- Smooth scrolling

- Scroll animations

- Lightbox gallery

- Cookie consent

- SEO optimized

- Fast loading

- Accessibility compliant

Color Palette:

- White (#FFFFFF)

Typography:

- Headings: Playfair Display

- Body: Inter

Style inspiration:

Luxury catering companies, Apple-style simplicity, modern European premium food brands.

Use beautiful food photography with professionally styled platters, elegant serving boards, premium desserts, soft natural lighting, and sophisticated presentation.

The design should feel luxurious, trustworthy, appetizing, and highly conversion-focused.

Generate the website using React + TypeScript + Tailwind CSS with reusable components, modern animations, SEO best practices, and clean code architecture.
